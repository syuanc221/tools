AI 設定

AI 搭配、自動命名衣服、尺碼建議會用你的 Claude API 金鑰，直接從這支手機連到 Anthropic，金鑰只存在這個瀏覽器。沒有金鑰也能用：「快速搭」照天氣和保暖度自動配，「複製提問」可以貼到 Claude App 問。

AI 拉平（OpenAI 生圖）

把穿搭照裡的衣服直接生成成白底平拍商品照，用的是 ChatGPT 背後的圖片模型。這要另外申請 OpenAI API 金鑰（platform.openai.com，跟 ChatGPT Plus 訂閱分開計費），照片會從這支手機直接傳給 OpenAI。
